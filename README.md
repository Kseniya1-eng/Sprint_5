# Stellar Burgers — автотесты на Selenium

Проект содержит автоматизированные тесты для учебного веб-приложения
[Stellar Burgers](https://stellarburgers.education-services.ru)
(приложение студента курса «React-разработчик» Яндекс Практикума).

Тесты написаны на **Python** с использованием **Selenium WebDriver** и **pytest**.
Основной целевой браузер — **Google Chrome** (ChromeDriver подтягивается
автоматически через Selenium Manager).

## Что проверяют тесты

| Раздел | Что проверяется |
|--------|-----------------|
| **Регистрация** | Успешная регистрация; ошибка для пароля короче 6 символов |
| **Вход** | Вход по кнопке «Войти в аккаунт», через «Личный Кабинет», через кнопку в форме регистрации, через кнопку в форме восстановления пароля |
| **Личный кабинет** | Переход в личный кабинет по клику на «Личный Кабинет» |
| **Конструктор** | Переход из личного кабинета в конструктор по клику на «Конструктор» и по логотипу Stellar Burgers |
| **Выход** | Выход из аккаунта по кнопке «Выход» в личном кабинете |
| **Конструктор** | Переходы к разделам «Булки», «Соусы», «Начинки» |

## Структура проекта

```
Sprint_5/
├── tests/                       # Директория с тестами
│   ├── __init__.py

│   ├── test_login.py            # Тесты входа в аккаунт
```

Тесты на одну функциональность сгруппированы в одном файле, все фикстуры —
в одном файле (`conftest.py`), как требует задание.

## Установка

Предварительные требования:

- Python 3.8+;
- Google Chrome (для запуска тестов; для Firefox установите Firefox и
  используйте `BROWSER=firefox`).

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Отдельно ставить ChromeDriver не нужно — Selenium 4.6+ скачивает его
автоматически (Selenium Manager).

## Запуск тестов

Запуск всех тестов в браузере Chrome:

```bash
pytest -v
```

Запуск конкретного файла:

```bash
pytest tests/test_login.py -v
```

Запуск без окна браузера (удобно для CI):

```bash
HEADLESS=1 pytest -v
```

Выбор браузера (по умолчанию Chrome):

```bash
BROWSER=chrome pytest -v
BROWSER=firefox pytest -v
```

## Как устроены тесты

- **Каждый тест автономен**: фикстура `driver` открывает браузер, тест
  выполняет свою задачу, в конце браузер закрывается (`driver.quit()`).
- **Генерация логинов (email)**: функция `helpers.generate_login()` создаёт
  уникальную почту в формате `имя_фамилия_когорта_3цифры@домен`
  (например, `kseniya_abramova_52_847@yandex.ru`). Имя и фамилия
  транслитерируются в латиницу — email не содержит кириллицы. Параметры
  (имя, фамилия, когорта, домен) настраиваются в `data.py`.
- **Генерация паролей**: `helpers.generate_password()` — корректный пароль
  (6+ символов); `helpers.generate_short_password()` — пароль короче 6
  символов для проверки валидации.
- Фикстуры `email`, `password`, `short_password` подключают генераторы
  к тестам через параметры тестов.
- Локаторы вынесены в `locators.py` и проверены на реальном DOM сайта;
  каждый локатор снабжён комментарием с описанием элемента.

## Замечания

- Регистрация использует уникальную почту, поэтому повторные запуски тестов
  не конфликтуют между собой.
- После успешной регистрации приложение редиректит на страницу входа `/login`,
  после входа — на главную `/`. Эти переходы используются как признаки
  успешных сценариев.
- Кнопка выхода в личном кабинете подписана «Выход».
